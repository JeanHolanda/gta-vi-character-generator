# 🎮 GTA VI – Character Generator

An interactive character generator inspired by the Grand Theft Auto universe, created exclusively for educational and portfolio purposes.

🔗 **Live Demo:** [GTA VI – Character Generator](https://jeanholanda.github.io/gta-vi-character-generator/)

---

## About the project

This project is an interactive character selector inspired by GTA VI, developed to practice and improve my front-end development skills.

The interface allows users to choose between iconic characters such as Lucia, Jason and CJ, or upload their own photo and transform themselves into a video game character using artificial intelligence.

The project was built using HTML, CSS and JavaScript, integrating Puter.js for AI-powered image generation.

---

## Sobre o projeto

Este projeto é um seletor interativo de personagens inspirado em GTA VI, desenvolvido para praticar e aprimorar minhas habilidades em desenvolvimento Front-End.

A interface permite que os usuários escolham entre personagens conhecidos, como Lucia, Jason e CJ, ou enviem uma foto própria para se transformar em um personagem de videogame utilizando inteligência artificial.

O projeto foi desenvolvido com HTML, CSS e JavaScript, integrando o Puter.js para geração de imagens com IA.

---

## 🎯 Purpose

The main goal of this project is to improve my Front-End development skills, especially:

- Manipulating the DOM with JavaScript
- Working with events and user interactions
- Handling image uploads using FileReader
- Working with asynchronous operations using async/await
- Integrating external AI services
- Building responsive interfaces
